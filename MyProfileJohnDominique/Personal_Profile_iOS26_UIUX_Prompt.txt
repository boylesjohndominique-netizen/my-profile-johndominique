# ASP.NET Core MVC Personal Profile — iOS 26-Inspired UI/UX Prompt

## ROLE

Act as a professional UI/UX designer and ASP.NET Core MVC frontend developer.

I am creating a **Personal Profile Web Page** for a Computer Laboratory Activity about:

**Razor Syntax and HTML Helpers in ASP.NET Core MVC**

The project must remain a simple educational ASP.NET Core MVC project, but the visual design should be significantly more polished, modern, unique, and aesthetically pleasing.

Create an **iOS 26-inspired visual experience** using modern web technologies while maintaining a completely original design.

Do not make the project unnecessarily complex.

The core purpose is still to demonstrate:

- Model
- Controller
- View
- Razor Syntax
- `@Model.Property`
- `@Html.LabelFor()`
- `@Html.TextBoxFor()`
- `@Html.EditorFor()`
- HTML `<form>`
- Submit button
- At least one additional HTML Helper

The UI should enhance the assignment rather than distract from the MVC concepts.

---

# 1. OVERALL DESIGN CONCEPT

Create a personal profile webpage that feels like a **personal digital identity card / modern portfolio profile**.

The visual direction should be inspired by the design principles of modern iOS:

- Liquid glass
- Translucent surfaces
- Soft blur
- Layered depth
- Floating elements
- Large rounded corners
- Minimal typography
- Smooth animations
- Subtle gradients
- Soft shadows
- Clean spacing
- Responsive layout

The design should feel:

**Personal + Futuristic + Minimal + Premium + Student-Friendly**

Do not directly copy Apple's interface.

Do not use Apple's logo, proprietary graphics, or exact layouts.

Instead, create an original interpretation of the aesthetic.
